# 数仓知识库本地个人版

## 启动

```powershell
python server.py
```

打开：

```text
http://127.0.0.1:5173
```

## 已实现

- 图文、链接两种导入入口；图文导入支持粘贴文字、直接粘贴截图 OCR，并在写入前弹窗确认标准格式内容。
- 导入后按问题行、小节标题、定义行、项目符号和流程描述自动生成 Question / Answer；只有问题没有答案时也会生成题目，后续可在题库中补充答案，并拦截相似问题。
- 标签只保存用户手动输入的内容；导入知识时必须至少指定一个标签。
- 知识库优先问答；知识库未命中时再进行外部搜索，并在页面明确标记为外部来源。
- 知识条目列表、标签筛选、编辑、删除。
- 题库列表按标签分组展示，支持随机抽取、人工新增、编辑、删除。
- 本地 JSON 持久化，无需数据库。

## 数据位置

```text
data/db.json
```

备份这个文件即可备份知识库数据。

## 说明

图片 OCR 在浏览器端通过 Tesseract.js 加载，首次使用需要网络。图片默认不保存原图；粘贴截图后会先识别并整理成文字，再弹出确认框供人工修改，保存后才合并进知识内容。外部搜索使用 DuckDuckGo 摘要接口，网络不可用时页面会显示外部搜索失败。

链接导入会解析普通公开网页正文。如果链接需要登录、飞书授权或企业内部权限，系统会停止导入并提示原因，避免把 URL 或登录页内容生成到题库里。
